# 教師執業證書 · 完整資料站

香港「教師執業證書」制度的一份完整、可查、可算的公開資料整理。
純靜態網頁，零外部依賴，可直接以 GitHub Pages 發佈。

## 內容

- **概念比較** — 教師註冊（終身） vs 執業證書（三年續期）
- **完整時間線** — 2025 施政報告 → 2026 立法會討論 → 2026 下半年草案 → 2028/29 實施
- **六大申請條件** — 逐項解讀，附「已建議／待公布／未交代」狀態表
- **150 小時 CPD** — 週期、核心培訓 30 小時、可計時數活動、**互動達標計算機**
- **申請流程** — 由受聘到持證上崗六步，以及每年 5–8 月行政高峰
- **誰要誰免** — 適用學校類別、代課豁免（每次 ≤3 天 且 12 個月 ≤30 日）
- **有效期與紀律** — 轉校、離職、取消註冊的連帶後果
- **16 條常見問題** — 摺疊式 FAQ
- **業界爭議** — 六個執行細節問題 + 支持方三大理由
- **行動清單** — 由今日到 2028 的八件事
- **資料來源** — 教育局、立法會文件、校長會意見書、六篇具名報道

## 技術

- `index.html` — 內容與結構（語意化 HTML、無框架）
- `assets/style.css` — 設計系統（CSS 變數、響應式、深色狀態卡、列印樣式）
- `assets/app.js` — 閱讀進度條、導覽 scroll spy、CPD 計算機

無 CDN、無建置步驟、無追蹤碼。字型使用系統字型堆疊（PingFang HK／Microsoft JhengHei）。

## 本機預覽

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 重要聲明

本頁為公開資料整理，**非教育局官方文件**，不構成法律意見。
截至 2026 年 11 月，教師執業證書仍屬立法建議，制度未生效；所有細節可能變動，
最終以《教育條例》（第 279 章）修訂條文及教育局正式指引為準。
